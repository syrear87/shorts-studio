# 파트너스 유입·클릭 증대 전략 회의 결과 (2026-08-14, 디렉터 지시)

> 전략팀 4렌즈(퍼널·상품·통로·레퍼런스) 병렬 회의 + 렌즈별 레드팀 공격. 제안 20건 → 채택 5 · 조건부 14 · 폐기 1. 중복 통합 후 실행 순서로 정리. 모든 기대치는 레드팀이 허수를 쳐낸 보수치만 남김.

## 회의가 찾아낸 핵심 진단 3개

1. **유일하게 팔아도 되는 지면(스토리)에서 안 팔고 있었다** — 현행 스티커 킷 이미지에 상품명이 아예 없음(스티커 자리 비우면서 같이 사라짐). 스티커 기본 라벨도 '링크'라 정보량 0.
2. **전략의 축이 틀렸다: "이 상품을 팔기"가 아니라 "쿠팡 앱을 열게 하기"** — 파트너스는 클릭 후 24시간 내 구매한 **모든 상품**이 실적 귀속. 4050 여성(실구매층)이 우리 링크로 앱을 열고 그날 장보기를 하면 그게 전부 우리 실적. → 상품 선정 기준을 "살 사람"에서 "눌러볼 사람"으로.
3. **계기판이 없다** — 스토리 뷰·스토리별 CTR 기록이 없어 어떤 개선도 판정 불가. 계측이 모든 제안의 전제조건.

## A. 즉시 실행 — 상주 세션 코드 작업 (디렉터 부담 0, 오늘 적용)

| # | 내용 | 근거 |
|---|---|---|
| A1 | **스티커 킷 이미지 v3**: 상품명 복원(카드 아래 여백) + "링크는 위 스티커를 탭" 1줄 + 스티커 위치 점선 가이드 + **대가성 고지 이미지 베이크**(하이라이트 대비) + 킷 캡션에 "스티커 문구를 상품명으로 바꿔주세요" 안내 | 정보량 0→1의 위생 수술. '구매·가격·주문' 단어는 영구 금지 |
| A2 | **스토리 CTR 계측**: 봇이 스토리 게시를 감지해 +20h 도달(reach) 자동 수집 → 파트너스 클릭과 대사해 스토리별 CTR 주간 리포트. **1스토리 1상품 원칙** 동반 | 유일한 무추정 제안. blind A/B 원칙의 선행 조건 |
| A3 | **죽은 상품 정리**: 삼계탕 스토리 재노출 종료(말복 오늘로 계절 소멸), 오디세이 방치, 15만원대 체중계는 허브 '복권'으로만 잔류 — 다음 체중 소재 때 2~3만원대 저가 체중계 병기 | 스토리는 하루 2회가 상한 = 매회가 클릭 티켓, 죽은 상품에 태우지 않기 |
| A4 | **허브 개편**: 상품 나열 → **편 단위 지식 아카이브**("영상에 나온 것들 정리") 프레임 | 프로필 방문 30~60/일(실측 역산) × 링크 클릭 5~15% = 허브 방문 월 45~270 (현재 0) |
| A5 | **지뢰 명문화**: ①가족·지인 구매로 15만원 채우기 **금지**(블로그 국룰이지만 어뷰징 정지 사유) ②자기 클릭 금지 재확인 ③고지 100% 기계 보장(A1 베이크) | 정지 = 실적 전체 리셋. 수익 증가가 아니라 파산 방지 |

## C. 루틴 변경 (디렉터 협조 — 하루 1~3분 내)

1. **킷 타이밍 11시 고정**: 제휴편 게시 직후(11:05) 킷 발송 → 11시대에 회신·게시되면 접속 피크(11~15시, 414~454명)를 스토리가 통째로 점유. 저녁(40~62명)과 7~10배 차이. 놓친 날은 기존대로.
2. **주 2회(월·목) 파트너스 리포트 스크린샷 회신** → 세션이 가격대×카테고리 전환 표 누적, 격주로 상품 배분 갱신. 상품 개별 판정 금지(n=1~3 노이즈), 묶음 단위만.
3. **상품 선정 축 변경**: ①24h 크로스셀 우선 — 1~3만원대 로켓배송 "눌러보고 싶은" 상품 ②4050 여성 반복구매 소모품(주방 위생·수분 등) ③계절 창 역산 — **내일(광복절 연휴 첫날) 아침 나들이템(선크림 등)이 첫 적용 시한** ④건강기능식품 제외(고지 붙는 순간 광고 — 표시광고법 리스크) ⑤스토리에 가격 숫자 박기 금지(변동 고지 위반 소지+속보임).

## D. 2주 한정 실험 (실측으로 존속 판정)

- **2프레임 퀴즈 스토리** (주 2회): 지식 퀴즈 프레임 → 정답+링크 프레임. 퀴즈 응답이 스토리 트레이 랭킹을 올려 내일의 뷰를 삼. 채널 톤과 완전 정합. 응답률 10% 미만이면 중단.
- **YT 커뮤니티 탭** (가용 확인 후 주 1회): 222구독에서 열려 있는지 확인부터. 기대치는 낮게(월 클릭 한 자릿수).
- **폭발일 편승**: 1만+뷰 감지 시 허브 재정렬 + 익일 첫 스토리 우선(연관 상품 있을 때만). 기대는 한 자릿수 클릭 — 자동이라 걸어만 둠.

## 폐기 1건

- 카드 마지막 장 프로필 유도 — 카드는 '본편'이라 상업 금지 위반 + 디렉터 기존 지침("형식 바꾸지 마라")과 충돌.

## 15만원 도달 경로 산수 (보수치)

스토리 2회/일 × 뷰 70~100 × 개선 후 CTR 2~4% ≈ **일 3~6클릭** → 24h 귀속 전환 ~10% → 주 2~4건 구매 × 객단가 2~3만원 = **주 판매액 5~10만원 → 15만원 도달 2~4주** (팔로워 성장분 배제한 바닥 시나리오. 성장 지속 시 단축). 전 가정은 A2 계측이 2주 내 실측으로 치환한다.
