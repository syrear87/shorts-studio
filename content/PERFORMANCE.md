# 채널 성과 실측 — 소재·제목 판단의 근거

> 갱신: `.venv/bin/python3 pipeline/analytics.py` (읽기 전용, 토큰 스코프 `youtube.readonly`·`yt-analytics.readonly`)
> 최초 분석 2026-08-02 (공개 17편, 채널 개설 6일차, 구독자 25명)

## 이 파일을 읽는 세션에게

소재 회의에서 **추측 대신 이 표를 근거로 말하라.** 다만 표본이 작다(17편, 그중 지속률 데이터는 8편). 여기 결론은 **잠정**이며, 새 데이터가 어긋나면 갱신하라.

---

## 1. 조회수를 가른 것은 소재가 아니라 **제목의 긴장**이었다

| 구간 | 제목 | 조회 |
|---|---|---|
| 상위 | 슈퍼태풍이 올라오는데 **오히려 더 더워진다고?** | 2,146 |
| 상위 | 강릉 밤 30도, 잠이 안 오는 건 **당신 탓이 아닙니다** | 1,936 |
| 상위 | 72년 만의 여자프로야구, **첫 투수는 한국인**입니다 | 1,893 |
| 상위 | 삼성전자 89조 벌었는데 **갤럭시는 적자**인 이유 | 1,713 |
| 상위 | 부산 아파트가 흔들렸다 — **진원지는 300km 밖 일본** | 1,553 |
| **하위** | 주식시장 비상정지 버튼, 올해만 9번 눌렸다 | **300** |
| **하위** | JYP 구내식당 김치값만 연 2억 2천만 원 | **296** |
| **하위** | 롯데카드, 내일부터 새로 못 만듭니다 | **186** |

상위는 전부 제목 안에 **모순·반전·통념 뒤집기**가 있다. 하위는 전부 **사실 통보**거나 **숫자만** 있다. 소재 분야(날씨·증시·스포츠·연예)는 상·하위 양쪽에 섞여 있어 변수가 아니었다.

**결정적 증거 — 내용과 유통은 별개다:**
"비상정지 버튼" 편은 **시청 지속률 112.6%로 전체 1위**인데 **조회수 300으로 최하위**였다. 본 사람은 끝까지 보고 되돌려까지 봤는데, 애초에 사람이 안 왔다. 대본을 아무리 잘 써도 제목이 무너지면 아무도 보지 않는다.

## 2. 조회수와 **구독 전환은 다른 축**이다 — 우리 병목은 구독이다

| 제목 | 조회 | 구독+ | **몇 회당 1명** |
|---|---|---|---|
| 예고편은 원래, 영화가 끝난 뒤에 틀었다 | 1,378 | **5** | **276회** |
| 슈퍼태풍이 올라오는데 오히려 더 더워진다고? | 1,936 | 3 | 645회 |
| 삼성전자 89조 벌었는데 갤럭시는 적자인 이유 | 1,615 | 2 | 808회 |
| 오늘 코스피를 무너뜨린 회사의 정체는? | 1,457 | 1 | 1,457회 |
| 증권앱 / 여름 1위 / 비상정지 버튼 | 977·1,528·301 | **0** | — |

**속보는 조회수를 주지만 구독을 거의 못 준다.** "오늘 이 정보"는 소비하고 끝나기 때문으로 보인다. 유일한 일상 유래형(예고편)이 구독 전환에서 2위의 **2.3배**였다 — "이 채널을 계속 보면 이런 걸 계속 알겠구나"를 만든 유일한 편이다.

⚠️ 이 결과는 자기관련성 게이트의 '예고편 어원 기각'과 충돌한다. **디렉터 판단 대기 중** — 게이트는 현행 유지하되 소재 회의에 이 수치를 제시하라. 러빙머드(기각)와 예고편(구독 1위)의 차이는 **"내가 직접 겪는 일이냐"**로 보인다(영화관 예고편은 매번 겪지만, 야구공 진흙은 겪은 적이 없다).

## 3. 시청 지속률 — 100% 초과는 정상이다(쇼츠 루프 재시청)

| 지속률 | 제목 |
|---|---|
| 112.6% | 주식시장 비상정지 버튼 |
| 103.8% | 삼성전자 89조 |
| 101.1% | 슈퍼태풍 |
| 85.6% | 여름 안 끝났는데 벌써 1위 |
| 76.5% | 코스피 무너뜨린 회사 |
| 75.2% | 예고편 |
| **51.3%** | **증권앱, 아직 못열었다? 당신 잘못이 아니다** |

**증권앱 편 51.3%는 압도적 최하이자 유일한 낙제**다. 977회나 갔는데 절반이 중도 이탈하고 구독은 0. 훅은 좋았으나 본문이 기대를 못 채운 경우로 보인다 — 훅에서 약속한 것을 본문이 갚는지 점검하라.

## 4. 유통 경로 — 정상이다

**SHORTS 피드 97.2%** (8,923/9,177). 나머지는 검색 0.8%, 채널 0.8%, 기타 1.1%.
→ 영상은 정상적으로 Shorts로 분류·유통되고 있다. **비원본 판정이나 분류 오류는 없다.**

## 5. Analytics 처리 지연 — 약 3일

2026-08-02 시점에 07-30까지만 처리 완료. 채널 통계의 "총조회 9,057"은 **처리 완료분**이고, 영상별 실시간 카운터 합계는 **약 20,700**이었다.

**"유효 Shorts 조회수 0"의 정체가 이것이다** — 자격 트래커는 처리 완료분을 쓰는데 채널이 6일차라 대부분 미처리 상태다. 여기에 누적 2만 회는 1단계 기준 300만의 **0.7%**라 반올림하면 0으로 표시된다. 고장이 아니다.

## 6. 시간대는 변수가 아니었다

같은 아침 슬롯에서 1,713(삼성)과 300(비상정지)이 갈렸고, 같은 저녁 슬롯에서 2,146(슈퍼태풍)과 186(롯데카드)이 갈렸다. **게시 시각으로는 성과가 설명되지 않는다.** 제목·소재가 변수다.
