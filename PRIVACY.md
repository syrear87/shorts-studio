# shorts-studio Privacy Policy

Last updated: 2026-07-28

shorts-studio is a personal, non-commercial command-line application
operated by an individual developer. It uses YouTube API Services to
upload self-produced videos to the developer's own YouTube channel and
to read analytics for that same channel.

## Data access and use
- The application authenticates only with the developer's own Google
  account via OAuth 2.0.
- It accesses: (1) the ability to upload videos to the developer's own
  channel, (2) read-only channel information, (3) read-only channel
  analytics.
- It does not collect, store, or process any data from any other person.
  There are no third-party users.

## Data storage and sharing
- OAuth tokens are stored locally on the developer's personal computer
  and are never shared with anyone.
- No user data is sold, shared, or transferred to third parties.
- No advertising or tracking of any kind is used.

## Third-party services
This application uses YouTube API Services. By using it, the developer
agrees to the YouTube Terms of Service
(https://www.youtube.com/t/terms) and the Google Privacy Policy
(http://www.google.com/policies/privacy).

## Revoking access
API access can be revoked at any time via Google security settings:
https://security.google.com/settings/security/permissions
